# Team Builder

[English](README.md)

設定した条件に基づいてチームを作成するWebアプリです。

## 使い方

1. **学生を追加** - チームに分けたい人の名前を入力します
2. **タグを付ける**（任意） - 学生をカテゴリ分けするタグを追加します（例：「パワースキル高」「グリーンフィールドグループ1」）
3. **関係を定義** - 学生のグループ分けルールを作成します：
   - `@Alice` - 特定の学生を参照
   - `#パワースキル高` - タグが付いた全学生を参照
   - `AND` / `OR` / `NOT` - 条件を組み合わせる
   - 括弧でグループ化： `( @Alice OR @Bob ) AND #Frontend`
4. **優先度を設定** - 各関係に優先度を設定します（高いほど優先的に満たされます）
5. **チームを生成** - チーム数を選んで生成ボタンをクリック

## ローカルで実行

```bash
# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

ブラウザで http://localhost:5173/TeamBuilder/ を開きます。

### デプロイ

```bash
npm run build
npm run deploy
```

プロジェクトをビルドしてGitHub Pagesにデプロイします。
